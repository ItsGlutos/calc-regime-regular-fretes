# Frete Líquido desktop 0.1.1

Correção do crédito no comparador. Substitui a 0.1.0 — se você já baixou a
versão anterior, use esta.

## O que mudou

- **O comparador agora usa o crédito do cálculo, não o percentual arredondado.**
  Ele reescalava o percentual já arredondado (2,39%) sobre o preço, então o mesmo
  frete do Simples/DAS aparecia com **R$ 23,90** de crédito e **R$ 976,10** de
  custo líquido, enquanto a calculadora mostrava **R$ 23,85** e **R$ 976,15**.
  As duas telas passam a fechar no mesmo centavo, e um teste trava essa igualdade.

Nada mais mudou: telas, regras e dados de demonstração são os da 0.1.0.

## Baixar e rodar

1. Baixe `FreteLiquido-0.1.1-win-x64.exe` abaixo e mova para uma pasta sua.
2. Dê dois cliques. Não precisa instalar .NET: o executável é autocontido.
3. Na primeira execução o Windows pode mostrar **"O Windows protegeu o seu PC"**
   (SmartScreen) porque o binário ainda não é assinado. Use **Mais informações →
   Executar assim mesmo**.

- **Sistema**: Windows 10 ou 11, 64 bits.
- **Validar o download**: o `SHA256SUMS.txt` traz o hash do `.exe`:

  ```powershell
  Get-FileHash .\FreteLiquido-0.1.1-win-x64.exe -Algorithm SHA256
  ```

## Limites conhecidos

- **Dados de demonstração**: o cronograma da LC 214/2025 e as regras de crédito
  são reproduzidos localmente, atrás de `ISimuladorFrete`; o motor fiscal oficial
  entra na fase 2.
- **Sem instalador**: não cria atalho no menu Iniciar nem aparece em
  "Aplicativos". MSIX/Inno Setup e assinatura de código estão no roadmap.
- **Windows x64 apenas** por enquanto.
